# data/screenshots

Referensbilder från manuell analys (t.ex. TradingView).

## Struktur

```text
screenshots/
  INDEX.md
  {source}/
    {symbol-with-dash}/
      {timeframe}/
        <filename>.png
```

Typiska `source`-värden: `manual`, `review`.

## Index

- `INDEX.md` listar alla skärmbilder med source, symbol och timeframe.
