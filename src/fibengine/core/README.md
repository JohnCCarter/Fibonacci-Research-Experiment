# core

Kärnlogik för motorbeslut (Lager A).

## Innehåll

- `config.py` settings-modeller och validering.
- `models.py` datamodeller (`Pivot`, `Swing`).
- `structure.py` marknadsstruktur (HH/HL m.m.).
- `scale.py` multi-skala confluence.
- `features.py` feature-beräkning per swing.
- `confirm.py` bekräftad/provisorisk swing.
- `scoring.py` ranking och val av swing-leg.
- `fib.py` fibnivåer från vald leg.
- `logging_conf.py` logging-konfiguration.
