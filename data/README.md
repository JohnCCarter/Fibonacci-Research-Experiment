# data

Datamapp för labels och lokala cache-filer.

## Struktur

- `labels/` manuellt facit (versioneras), kategoriserat per exchange/symbol/timeframe + `INDEX.md`.
- `raw/` cachad marknadsdata (versioneras inte), kategoriserat per exchange/symbol/timeframe/limit + `INDEX.md`.
- `screenshots/` referensbilder (versioneras inte), kategoriserat per source/symbol/timeframe + `INDEX.md`.
